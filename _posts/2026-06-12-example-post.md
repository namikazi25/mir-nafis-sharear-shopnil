This is an example post for the new blog workflow.

Posts now live as Markdown files in the `_posts/` directory, which means the site can render them automatically with Jekyll. The blog page lists posts from `site.posts`, newest first, and each post gets its own clean page using the existing site style.

With Decap CMS configured at `/admin/`, new posts can be drafted, edited, and published from a browser UI instead of hand-writing HTML files.
